# ГЛУХОЙ ЧАС / DEAD HOUR — кооперативный онлайн-хоррор для Яндекс Игр

Кооперативный хоррор-побег на 1–4 игрока на **собственном движке WebGL 2**, без сторонних
библиотек и без файлов-ассетов. Все текстуры, звуки, музыка и модели генерируются кодом при
загрузке, поэтому архив для Яндекса весит около 150 КБ.

## Что внутри

### Движок (`client/src/engine`)
- **Рендер**: forward HDR, PBR-подобное освещение (GGX/Blinn, Френель), карты нормалей,
  до 16 точечных ламп и 4 фонарика одновременно.
- **Мягкие тени** от фонариков всех игроков: атлас теней, Poisson PCF до 16 выборок с поворотом
  на пиксель; на слабых устройствах — аппаратный PCF.
- **Объёмный свет**: лучи фонарика в пыли и тумане с учётом теней.
- **Постобработка**: bloom (цепочка mip-уровней), тонмаппинг ACES, виньетка, плёночное зерно,
  хроматическая аберрация и искажения от страха, красная пульсация при ранении, FXAA.
- **Процедурные материалы** (26 шт., с картами нормалей и шероховатости): бетон, облупленная
  краска, ржавчина, плитка, обои, ковёр, кирпич, дерево, асфальт, черепица, ткань и другие.
  Генерируются параллельно в Web Workers.
- Частицы пыли, светящиеся в луче, ореолы ламп, мерцание ламп, AO в углах.
- **Физика**: капсула игрока против AABB, подъём на ступеньки, прыжки, приседание (с проверкой
  потолка), лучи, линия видимости, физические бутылки и банки с отскоком и трением.
- **Звук**: всё синтезируется (шаги по 8 поверхностям, монстры, двери, музыка погони и
  напряжения, эмбиент), 3D-звук с HRTF и приглушением звука за стенами, шины громкости.
- **Ввод**: клавиатура + мышь (pointer lock), геймпад, сенсорное управление (стик, обзор пальцем,
  кнопки действий).
- **Динамическое разрешение** держит частоту кадров; 4 пресета качества.

### Игра (`client/src/game`)
- **3 карты** со своей цепочкой загадок (в духе Escape the Backrooms) и уникальным монстром:

| Карта | Монстр и его механика | Задачи |
|---|---|---|
| Тюрьма «Чёрный Яр» | **Надзиратель**: слепой, охотится **на звук** (бег, броски, проваленный ремонт). Присев, вы двигаетесь бесшумно; вентиляции для него недоступны | 3 предохранителя → питание блока → 4 рычага по схеме на табло → код из 4 записок → ключ от ворот → побег |
| Город-призрак Тихий Лог | **Пугало**: двигается, **только когда на него никто не смотрит** (в темноте нужно светить фонариком) | генератор с проверками навыка → частота радио из записки → код склепа → канистры (одна — из заработавшей колонки) → ключ → автобус |
| Жёлтые комнаты | **Мотылёк**: летит **на включённые фонарики** и лампы, гасит свет вокруг; брошенная бутылка его отвлекает | 3 вентиля → кнопки с символами в порядке со стены → 3 ключ-карты → лифт |

- **Механики выживания**: выносливость и бег (с изнеможением), приседание, прыжок, фонарик с
  батареей (мерцает при разряде и рядом с монстром), запасные батарейки, **аптечка** (лечение
  удержанием), **адреналин** (рывок, полная выносливость, лечение или подъём из «поверженного»
  состояния), шкафчики для пряток (если монстр видел, как вы спрятались, он вас достанет),
  бутылки и банки для отвлечения, страх (пульс, дыхание, визуальные искажения).
- **Кооп в духе DBD**: два удара — «повержен», 60 секунд до гибели, напарник поднимает
  удержанием. После удара игрок получает короткий рывок скорости. Можно наблюдать за
  выжившими после смерти или побега, ставить метки и пользоваться быстрыми фразами.
- **Боты** занимают свободные места: собирают и несут предметы, дёргают рычаги, чинят генератор,
  крутят вентили, поднимают упавших, убегают от монстра, следуют за игроком. Против Пугала
  держат его в поле зрения, против Мотылька гасят фонарь.
- **Прокачка**: опыт, уровни, монеты, 8 навыков (выбирается 2), дневной бонус.
- **Кастомизация**: тон кожи, телосложение, причёски и цвет волос, 8 головных уборов,
  10 курток, 5 брюк, 5 масок, рюкзаки и рация, 6 цветов фонарика. Часть предметов открывается
  с уровнем, часть покупается за монеты.

### Онлайн (`server/`)
- Свой сервер на Node.js **без зависимостей** (WebSocket RFC 6455 написан с нуля).
- **Лобби как в DBD**: персонажи отряда стоят у костра, отряд с **кодом приглашения**,
  статус готовности, исключение из отряда, режим «Только друзья».
- Режимы **Соло / Дуо / Трио / Сквад**; матчмейкинг объединяет отряды. Если за 20 секунд
  игроков не хватило, свободные места занимают боты.
- Модель «авторитетный хост»: хост считает монстра, ботов и задачи, остальные получают
  состояние. Если хост вышел, его роль переходит другому игроку.
- Ограничение частоты и размера сообщений, очистка ников, проверка дистанции для действий.
- Без сервера игра работает офлайн с ботами, так что модератор всегда может пройти игру.

## Запуск

```bash
npm start                # сервер + клиент: http://localhost:8080
npm test                 # тесты сервера и карт
npm run test:smoke       # браузерный smoke-тест (Playwright, скриншоты в tests/screenshots)
node tests/gameplay.mjs  # прохождение всех трёх карт до побега
node tests/multiplayer.mjs  # два браузера: отряд по коду, матч, синхронизация, смена хоста
npm run build            # архив для Яндекса: dist/dead-hour-yandex.zip
```

Нужен Node.js 18 или новее; зависимостей нет.

## Публикация в Яндекс Играх

1. Разверните сервер на хостинге с HTTPS (VPS, Docker, Render и т.п.): `PORT=8080 node server/server.js`
   за обратным прокси с TLS. WebSocket доступен по пути `/ws`, проверка работы — `/health`.
2. Соберите архив с адресом сервера:
   `SERVER_URL=wss://ваш-домен/ws npm run build`
3. Загрузите `dist/dead-hour-yandex.zip` в консоль разработчика Яндекс Игр.
4. В консоли укажите: возрастной рейтинг **16+**, жанр «Хоррор / Приключения», языки ru/en/tr,
   ориентацию на мобильных — **горизонтальная**, лидерборд `escapes` (необязательно).

### Соответствие требованиям Яндекс Игр
| Требование | Реализация |
|---|---|
| SDK подключён по `/sdk.js`, `YaGames.init()` | `index.html`, `src/game/sdk.js` |
| LoadingAPI.ready() после загрузки (1.19.2) | `main.js`, вызывается при показе меню |
| GameplayAPI.start/stop | начало матча, пауза, меню, итоги |
| Пауза и звук при сворачивании, `game_api_pause/resume` | `setupPlatformEvents`, AudioContext останавливается |
| Реклама только через SDK, в естественных паузах, со звуком выкл. | полноэкранная — между матчами; за вознаграждение — ×2 награда и монеты |
| Автоопределение языка | `ysdk.environment.i18n.lang` → ru/en/tr |
| Облачные сохранения | `player.setData/getData` + localStorage |
| Нет внешних ссылок и ресурсов, нет сторонних покупок | все ресурсы в архиве, покупок нет |
| Нет выделения текста, контекстного меню, зума и прокрутки страницы | CSS + `installPageGuards()` |
| Работа на ПК и мобильных, адаптивный интерфейс | сенсорное управление, safe-area, подсказка повернуть экран |
| Архив ≤ 100 МБ, `index.html` в корне, латинские имена файлов | проверяется в `tools/build.mjs` |
| Без чата со свободным текстом | только быстрые фразы и метки |
| Сдержанный контент | без крови и жестокости, надписи мелом |

## Управление (ПК)
WASD — ходьба, Shift — бег, C/Ctrl — присесть, Пробел — прыжок или проверка навыка,
E/ЛКМ — действие, F — фонарик, R — батарейка, G/ПКМ — бросить, Q (удерж.) — аптечка,
X — адреналин, Z/СКМ — метка, 5–8 и V — быстрые фразы, Esc — пауза. Поддерживается геймпад.

## Структура
```
client/            # то, что попадает в архив
  index.html, css/
  src/engine/      # движок: gl, renderer, shaders, textures, mesh, physics, audio, input
  src/game/        # игра: maps/, world, puzzles, monsters, player, bots, match, net, sdk …
  src/ui/          # меню, лобби, HUD, модальные окна
server/            # ws.js (WebSocket), lobby.js (отряды/матчмейкинг/ретрансляция), server.js
tools/build.mjs    # упаковка zip
tests/             # тесты сервера, карт, браузерные e2e
```
